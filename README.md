# Tense Trainer 2.0

Next.js-тренажёр английских времён для школьников 10–14 лет и начинающих. В одной странице собраны:

- наглядная таблица всех 12 времён
- смешанные тренировки по нескольким временам
- отдельная разминка `to be`
- локальный прогресс и повтор слабых мест
- отдельные учебные страницы для органического поиска

## Стек

- Next.js App Router
- React 19
- TypeScript
- `localStorage` для темы и прогресса

## Локальный запуск

```bash
npm install
npm run dev
```

Продакшен-сборка:

```bash
npm run build
npm run start
```

## Публикация и проверка

Production — статический сайт Render `tense-trainer-prod`, ветка `main`, каталог `out`, основной домен `временаванглийском.рф`. Vercel используется для preview. После `npm run build` экспорт можно просмотреть командой `python3 -m http.server 3101 --directory out` (команда `next start` не обслуживает статический экспорт).

Перед выпуском: `npm test`, `npm run lint`, `npm run build`. Затем проверить браузером сессию, сохранение прогресса, мобильный экран и реальные опубликованные URL. Автоматическая сборка Render ещё не означает успешную публикацию: дождаться состояния live и сверить результат.

Главная содержит таблицу 12 времён. Ещё шесть адресов находятся в `content/topics.ts`; каждый сразу настраивает тренажёр для своей темы. Стандартный формат URL — с завершающим слешем. Canonical и sitemap должны соответствовать основному домену.

Метрика 114096471 загружается только на основном домене и после разрешения посетителя. Вебвизор выключен. Настройки разрешения доступны на странице `/privacy/`. События и дальнейшая проверка спроса описаны в `docs/SEO-MONETIZATION.md`.

## Структура

- `app/` — маршруты, layout, metadata, robots, sitemap, manifest
- `components/` — UI главной страницы, тренажёр, footer
- `content/` — данные по 12 временам и разминка `to be`
- `lib/` — типы, генерация вопросов, прогресс и localStorage
- `docs/` — старые заметки по SEO и временам как справочный материал

## Что важно в релизе

- В первой версии нет аккаунтов и бэкенда
- Главная — общая таблица и выбор тем; шесть самостоятельных страниц — практика и объяснения
- Канонический домен для production остаётся `временаванглийском.рф`
- Vercel используется как preview-среда, Render — как production-среда
