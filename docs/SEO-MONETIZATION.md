# Развитие Tense Trainer

Обновлено 5 ноября 2026. Аудит и исходные наблюдения хранятся локально в audit-2026-11-05; они не входят в публичный релиз.

## Измерения

Счётчик Метрики 114096471 работает только на основном домене после разрешения пользователя. Вебвизор выключен. События: training_start, answer_submit, hint_open, training_complete. Тексты ответов, имя и контакты ученика не передаются. Вопросы внутри тренировки не считаются новыми просмотрами страниц.

Прогресс в браузере не является статистикой аудитории владельца. Метрика отражает только разрешивших её пользователей; учитывать это при расчёте конверсий. Исторические посещения не восстановлены; байты Render не пересчитываются в людей.

## Поиск и содержание

Главная отвечает за таблицу всех времён и выбор тем. Шесть посадочных: Present Simple, Present Continuous, Past Simple, to be и два сравнения. На каждой — собственные метаданные и canonical, видимое правило, примеры, FAQ и тренажёр нужной темы. Страницы включены в sitemap и перелинкованы.

Вордстат при проверке 05.11.2026 показывал данные за 08.09–07.10 по всем регионам: около 1,5 тыс. широких запросов про тренажёр английских времён и 64,6 тыс. со словами present simple упражнения. Это пересекающиеся группы запросов, не уникальные люди и не прогноз посещений. Сервис предупреждал о неполной доступности данных. Старые неподтверждённые оценки спроса и ставок дохода удалены.

## Проверка перспектив

В течение 90 дней сравнивать полные недели: индексация, поисковые показы и клики, запуски и завершения тренировок, возвращения на другой день. При малой выборке дополнять статистику наблюдением за 5–10 пользователями. Предварительные ориентиры пилота: начало у 30% посетителей, завершение у 50% начавших. Это управленческие гипотезы, а не отраслевые нормативы.

Доход проекта не подтверждён. Сначала проверить полезность и поисковый поток, затем один согласованный партнёрский оффер после результата. Реклама — дополнительная модель после модерации, с измерением фактического дохода.

AdSense для российского аккаунта не закладывать в план: https://support.google.com/adsense/answer/15282937?hl=en. Условия РСЯ проверять перед подключением: https://yandex.ru/support/partner/ru/yan-rules/. Произвольные ставки не использовать как финансовый прогноз.

## Проверки перед публикацией

npm test, npm run lint, npm run build. Проверить экспортированные canonical, sitemap и ссылки. В браузере пройти старт → ответ → результат → перезагрузка с сохранённым прогрессом. После публикации проверить реальные URL и приём событий Метрикой.
